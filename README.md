## 소리 자동 재생
브라우저는 보안 정책상 터치 전에는 소리를 막는다. 게임은 열리자마자 재생을 시도하고, 막히면 첫 터치에 바로 시작한다.
윈도우 부스 PC에서는 `KELI_부스실행.bat`을 게임 HTML과 같은 폴더에 두고 실행하면 Chrome(없으면 Edge)이 자동 재생 허용·전체화면으로 열린다. 종료는 Alt+F4.

## 파일
- `index.html` : 게임 전체(이미지·QR·사운드 포함 단일 파일, 오프라인 실행 가능)
- `KELI_부스실행.bat` : 윈도우용 부스 실행기(소리 자동 재생·키오스크 모드)
- `apps-script/Code.gs` : 참여 기록을 구글 시트로 받는 Apps Script

## 참여 기록 저장 방식
1. 기록은 먼저 부스 기기 브라우저에 저장된다(인터넷이 없어도 유실되지 않음).
2. 인터넷이 연결되면 1분마다 구글 시트로 자동 전송된다. 같은 기록은 시트에 한 번만 저장된다.
3. 운영 도구(왼쪽 위 KELI 로고 5번 빠르게 터치)에서 전송 현황 확인, 즉시 전송, CSV 내려받기를 할 수 있다.

## 구글 시트 연결(최초 1회)
1. Apps Script 열기: https://script.new (또는 참여기록 시트 → 확장 프로그램 → Apps Script)
2. `apps-script/Code.gs` 내용을 붙여넣고 저장. script.new로 만들었다면 코드의 `SHEET_ID`에 참여기록 시트 ID를 넣는다
3. 배포 → 새 배포 → 유형: 웹 앱 → 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포 → 권한 승인
4. 웹 앱 URL(`https://script.google.com/macros/s/…/exec`) 복사
5. 부스 기기에서 게임 열기 → KELI 로고 5번 터치 → 주소 입력 → "주소 저장·연결 확인"

시트 주소는 이 저장소에 넣지 않고 부스 기기에만 저장한다(공개 저장소에 수신 주소가 노출되지 않도록).
